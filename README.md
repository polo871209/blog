# PoLog

Personal blog. Built with [Astro](https://astro.build). Live at [polo.is-not-a.dev](https://polo.is-not-a.dev).

Theme: [Kanagawa Lotus](https://github.com/rebelot/kanagawa.nvim) palette, [Fira Code](https://github.com/tonsky/FiraCode) mono. The home page renders a three.js sakura garden, ported from `garden-tree`.

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build      # static output to dist/
pnpm preview    # serve the build locally
```
